# Ridwanul Hoque Kawsar - Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, and Lucide icons. It features a responsive navigation bar, theme toggle, professional introduction, skills, learning history, competitive programming experience, project details, direct contact links, and a downloadable PDF résumé.

- 2+ years of competitive programming practice, 600+ problems solved, and a 2-star CodeChef rating
- Phitron course completed; Programming Hero Web Development Level 1 in progress
- Four featured pinned repositories: BazarDor, Keep Your Body Fit, Dev-Stack, and DevConf 2026

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. The site is configured for Vercel's Vite preset and deploys from the `main` branch.
